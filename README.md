<details>

### 🤖 Eon Resume — AI-Powered Resume Builder
Transforms structured user input into professional, prebuilt resume templates — content and presentation are fully decoupled.

**Stack:** Next.js 15 · React · TypeScript · Prisma · MongoDB · Clerk · Groq API · Tailwind · Puppeteer · pdf-lib

<details>
<summary><b>Engineering deep dive</b> (click to expand)</summary>
<br>

- Form-driven resume data modelling, separated from template rendering
- Reusable, swappable template rendering layer
- AI-assisted content generation — migrated from OpenAI to Groq API for cost/latency
- Authenticated user workflows end-to-end
- Document-generation pipeline: HTML → PDF via Puppeteer + pdf-lib

**Links:** [Live App](https://nextjs-15-ai-resume-builder-navy.vercel.app/) · [Repository](https://github.com/Maqoba-Jiyane/nextjs-15-ai-resume-builder)

</details>
