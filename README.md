A regional job-discovery system designed to ingest, normalise, and distribute time-sensitive vacancy data at scale.

**Stack:** Next.js · TypeScript · Prisma · MongoDB · Clerk · Vercel · Cloudflare

<details>
<summary>⚙️ <b>Architectural Deep Dive</b> (Click to expand)</summary>
<br>

*   **State Machine Lifecycle:** Designed automated runtime rules to handle chronological state validation (automatic archiving, caching, and re-indexing expired entities).
*   **SEO Engine:** Built an programmatic static/dynamic generation blend resulting in 946 programmatic pages maintaining a consistent ~9% CTR.

### 🤖 Eon Resume — Decoupled AI Asset Pipeline
An AI-driven engine that decouples resume content schemas from heavy layout engines, producing consistent document structures.

**Stack:** Next.js 15 · TypeScript · Prisma · MongoDB · Groq API · Puppeteer · pdf-lib

<details>
<summary>⚙️ <b>Architectural Deep Dive</b> (Click to expand)</summary>
<br>

*   **Latency Optimisation:** Migrated critical processing loops from OpenAI models to Groq API systems, cutting downstream API latency while preserving input validation patterns.
*   **Isolated Compute Workers:** Implemented an asynchronous print pipeline converting JSON payloads into valid PDF byte buffers using Puppeteer and `pdf-lib`.

📥 **Artifacts:** [Live App](https://vercel.app) · [Repository](https://github.com/nextjs-15-ai-resume-builder)
</details>

### 🧠 ContextTo — Multi-Tenant Knowledge RAG Engine
A highly isolated backend infrastructure managing parallelized document scraping, text vector embedding, and ingestion patterns.

**Stack:** NestJS · Python · FastAPI · PostgreSQL · Prisma · Redis · BullMQ · Docker

<details>
<summary>⚙️ <b>Architectural Deep Dive</b> (Click to expand)</summary>
<br>

*   **Distributed Processing:** Managed a dual-runtime structure where a NestJS API handles upstream coordination while a Python FastAPI cluster handles deep textual parsing.
*   **Concurrency Control:** Integrated BullMQ and Redis backplanes to handle rate-limiting and job retries during massive bulk uploads.

📥 **Artifacts:** [Repository](https://github.com/ContextTo)
</details>
